The iTrust system allows patients or personal health representatives to answer a series of questions related to a previous office visit. These questions focus on the amount of time spent waiting in the waiting room and examination room before seeing the physician, as well as satisfaction with the office visit and the treatment or information received. The responses to these questions are stored for future reference.

Additionally, the system allows users to view physician satisfaction survey results based on specific criteria. The user can provide a zip code (or hospital code) and an optional physician type (e.g., general, surgeon, heart specialist, pediatrician, OB/GYN) from a pull-down list. The system then displays a list of physicians of the selected type who practice in the provided zip code (or a matching first three digits of the zip code). For each physician, the following information is displayed:

- Name
- Address
- Average wait time in the waiting room
- Average wait time in the examination room before seeing the physician
- Average office visit satisfaction
- Average satisfaction with treatment or information
- Percentage of office visits for which satisfaction information is available

If the user enters an invalid zip code, they are prompted to try again.
