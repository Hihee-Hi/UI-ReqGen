# Dronology - chunk-01 local themes

## T-01 — Drone Flight Route Management
Users can create, edit, and manage flight routes for drones. This includes adding, modifying, and deleting waypoints, as well as organizing routes in a list or map view. The system provides tools for inputting specific details like altitude and speed, and ensures data accuracy through validation and confirmation prompts.

## T-02 — Drone Monitoring and Control
The system provides a comprehensive interface for monitoring and controlling active drone flights. Users can view real-time status, manage flight operations, and execute emergency commands such as returning drones to base or hovering. The interface supports both individual and group drone management, enhancing operational efficiency.
