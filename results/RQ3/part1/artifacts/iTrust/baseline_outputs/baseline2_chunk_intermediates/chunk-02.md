# iTrust - chunk-02 local themes

## T-01 — User Identification and Selection
The system allows users to search for and confirm the identity of other users using a unique Medical ID (MID). It ensures accurate user selection and provides error handling for invalid IDs.

**Source files:**
- util_getUser.txt

## T-02 — Dynamic User Interaction Frame
A feature that provides a movable frame within a web page to display additional user-related content or features dynamically, enhancing user interaction without disrupting the main workflow.

**Source files:**
- util_getUserFrame.txt

## T-03 — Password Reset Process
The system facilitates password reset by verifying user identity through MID and role, followed by answering a security question. It ensures secure password management and provides error handling for incorrect inputs.

**Source files:**
- util_resetPassword.txt

## T-04 — Fake Email Archive for Testing
A tool for viewing and verifying fake emails sent from the system, including details like recipients, sender, subject, and content, to ensure email functionality accuracy during testing.

**Source files:**
- util_showFakeEmails.txt

## T-05 — Transaction Log for System Evaluation
A logging tool that records all system transactions with details such as date, transaction ID, type, and user IDs involved, aiding in troubleshooting, auditing, and testing system operations.

**Source files:**
- util_transactionLog.txt
