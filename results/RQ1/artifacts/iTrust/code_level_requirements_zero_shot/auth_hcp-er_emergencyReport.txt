When using the emergency reporting system, users such as healthcare providers in an emergency room setting can generate a detailed report for a specific patient. Initially, if you are not in print mode, make sure to have identified the patient by using their ID. If the patient ID isn't already set in the session, you will be redirected to a page to obtain it.

Once the patient ID is confirmed, the system processes the creation of an emergency report for the healthcare providers involved with this patient. This involves checking the patient's declared healthcare providers and sending them notifications. The report includes crucial information about the patient, such as their full name, age, gender, emergency contact details, any known allergies, blood type, critical diagnoses, current prescriptions, and immunization records. If any section has no information available (like allergies or prescriptions), it explicitly states that no records are available.

If required, the report can also be prepared for printing by toggling the print setting, allowing you to generate a print-friendly version of the document. This ensures that all essential patient information is readily available to assist emergency medical personnel in making informed decisions quickly.
