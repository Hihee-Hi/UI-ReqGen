When a user decides to end their current session with the system, they can choose to log out. Upon initiating a logout, the system will end the active session, ensuring that any personal data or session-specific information is secured and closed. This action reduces the risk of unauthorized access if someone else attempts to use the same device or browser session afterward. Once the session is terminated, the user will be taken back to the main landing page of the application, providing a clean exit and a clear visual cue that they have successfully logged out. This process is vital for maintaining user privacy and security within the application.
