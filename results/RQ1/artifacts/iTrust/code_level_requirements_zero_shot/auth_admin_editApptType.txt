As an administrative user managing appointment types, you can customize the categories of appointments within your system. On the page, you will find a form to either add new appointment types or update existing ones. To create a new type, input the desired name and duration, then submit the form by clicking "Add Type." For updates, you can click on an existing appointment type from the list displayed, which will autofill the form with the selected details. After making any necessary changes, click "Update Type" to save your modifications. The system also provides feedback through messages to guide you in correcting any input errors.
