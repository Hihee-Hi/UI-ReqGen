As a user interacting with this system, you have the ability to add a new Public Health Authority (PHA) to the organizational records. Begin by ensuring you have the new personnel's first name, last name, and a valid email address ready. If the individual lacks a personal email address, use the organization-provided email address. Fill out this information in the respective fields provided in the form on the page. Upon completing the form, submit it to register the new PHA.

Once the form is submitted, the system will process the details and create a new personnel entry. If successful, the page will display a confirmation message along with the new Medical ID (MID) assigned to the PHA, as well as a temporary password. Ensure this information is securely delivered to the new personnel for their records and access. In the event of any errors during this process, such as invalid form entries, the system will display an error message indicating the issue.
