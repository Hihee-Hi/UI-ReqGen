Healthcare professionals can use this interface to manage their list of monitored patients. Initially, the system ensures that a specific patient has been selected for modification by requiring a patient ID. If not, they are redirected to select a patient from another page. Once a patient is chosen, the user can see options to either add the patient to their monitoring list or remove them if they are already included. After an action of adding or removing a patient, the user's list is updated, and a confirmation message is displayed, such as "Patient [Name] Added" or "Patient [Name] Removed". If they wish to switch to a different patient, they can do so using the provided option. This functionality supports healthcare patient management by allowing easy updates to whom they are actively monitoring.
