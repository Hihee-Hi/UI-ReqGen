Upon logging into the medical portal, you will first need to select a patient by using their unique identification number. Once a patient ID is provided and validated, the system will display a summary of all laboratory procedures associated with that patient. In this summary, you can view detailed information such as the patient's name, lab code, access rights, and the status of each lab procedure. You will also see commentary, results, related office visit information, and the date each procedure was last updated. If you need to make changes to a specific procedure, you can click the 'Update' link next to the relevant entry, which allows you to modify the existing records. This process helps manage and track laboratory procedures efficiently in a healthcare setting.
