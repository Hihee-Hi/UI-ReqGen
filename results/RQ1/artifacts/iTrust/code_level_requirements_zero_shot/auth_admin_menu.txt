In this system, as an admin user, you can perform several key operations to manage healthcare roles and system settings. To start, you have the option to add new healthcare roles such as healthcare providers, emergency responders, and public health administrators. If you need to make modifications, you can edit various settings including appointment types, hospital assignments for healthcare providers, and different medical codes, which are integral to healthcare processes. These codes include procedure codes, drug codes, diagnosis codes, and laboratory codes. Additionally, you have the ability to update personnel records and manage your own demographic information. The system also facilitates sending appointment reminders and tracking these through an outbox. Other administrative functions include managing hospital listings, configuring session timeout settings, and reviewing satisfaction survey results to improve service quality. These activities ensure the healthcare facility's operations are efficiently managed and aligned with users' needs and expectations.
