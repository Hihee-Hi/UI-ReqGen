You can use this interface to report telemedicine monitoring data for a specific patient. When visiting the page, ensure to select the patient you want to report the data for; if not selected, you'll be redirected to a list to choose from. Once a patient is selected or assigned a session, you can fill out the form with the patient's systolic and diastolic blood pressure readings and glucose level. After completing the form, submit it to add the monitoring data. If the data is added successfully, you'll see a confirmation message. If there's an invalid entry, such as non-numeric values, or other validation errors, you'll be informed with specific messages to correct inputs.
