As a user interacting with this system, you have the ability to update the personal information of staff members. When editing a personnel record, you will begin by either selecting or being redirected to the correct personnel ID. You can then fill out or update fields related to the individual's first and last name, address, city, state, zip code, phone number, and email address. To save the changes, you will submit the form by clicking the "Edit Personnel Record" button. If the update is successfully completed, you will see a confirmation message. If there are any errors, such as invalid input, you will receive feedback to correct the information. Additionally, if you need to set or reset a password for the staff member, you can use the link provided on the login page designated for password management.
