As a healthcare professional using this patient monitoring system, you are able to securely view a list of patients whose health data is being monitored remotely. By logging into the system, you access a dashboard where you can see a table labeled "Patients" that lists each patient currently being monitored. This system allows you to observe the list of monitored patients without generating additional log entries. Each patient's name in the list serves as a clickable link. Clicking on a patient's name will allow you to navigate to a section where you can add or view telemedicine data specific to that patient. The system is designed to help you manage and monitor patients effectively, ensuring that you have the necessary information at your fingertips to provide quality remote healthcare.
