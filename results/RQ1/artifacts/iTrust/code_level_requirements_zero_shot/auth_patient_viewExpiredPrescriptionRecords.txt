To view expired prescription records, start by visiting the section labeled with the title, "Get My Expired Prescription Reports." As a patient, your details will be retrieved to generate a list of expired prescriptions specifically related to you. If there are no expired prescriptions on record, you'll see a message stating, "No prescriptions found." If there are expired prescriptions, they will be displayed in a tabular format, showing information like the ND code, medication description, duration from start to end, and the name of the prescribing healthcare professional. You can click on the ND code link for more detailed prescription information or on the prescribing doctor's name to learn more about them. This system helps you quickly access and review your past prescriptions that are no longer active.
