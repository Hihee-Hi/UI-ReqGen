This section allows healthcare professionals to manage and update a patient's basic health records. Initially, users need to select a patient by providing a valid patient ID; otherwise, they will be redirected to obtain it. Once the patient's ID is confirmed, users can view a comprehensive history of the patient's health parameters, such as height, weight, smoking status, blood pressure, and cholesterol levels. If the healthcare professional wants to add a new health record, they can do so by clicking the "Add Record" button, which allows them to input new values. Upon submission, the system validates the input data, updates the records, and confirms the action with a success message. This ensures that healthcare providers can efficiently keep track of and update patient's vital health statistics for consistent monitoring and care.
