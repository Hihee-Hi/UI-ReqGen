As a user, you have access to a set of test utilities for a specific system. These utilities allow you to prepare and manipulate test data necessary for the system's functionality. Before you can use these utilities, you must ensure your system is configured correctly. This involves setting a specific property related to your development environment. Once configured, you can view a list of available data generators. These generators can be executed by simply clicking the corresponding link, which will trigger a process in the background to produce or reset test data. This is particularly useful during development and testing phases to ensure that the system has the necessary data for various scenarios.
