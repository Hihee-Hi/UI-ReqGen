This interface allows authorized administrative personnel to add new healthcare providers into the system. As an administrative user, you can input the first name, last name, and email address of the new healthcare provider. If the new provider does not have a personal email, you should use a designated email address for password recovery purposes. Upon submission, the system will create a new account for the provider, assigning them a medical identification number and a temporary password. You will see a confirmation message with the new provider's details, which you need to communicate to the provider. If any errors are encountered during form submission, such as validation issues, they will be displayed for correction. After successfully adding the new provider, you can proceed to update their details if necessary.
