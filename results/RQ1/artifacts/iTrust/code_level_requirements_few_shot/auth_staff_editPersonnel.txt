As a staff member using this system, you would:

Log in and access the page to edit personnel information. If the system has not identified the personnel you intend to edit, it will redirect you to select a personnel ID before proceeding.

See the personnel's existing details like first name, last name, address, city, state, zip code, phone number, and email already filled in the form fields. These details can be updated directly in the form fields by entering changed values.

Ensure all required fields are completed accurately. Submit the updated information via the form to apply the changes.

The system provides immediate feedback on the success of your update. If any input format violates form rules, you will receive an error message guiding you to correct it.

While changing personnel information, note that passwords are managed separately. Use the "Reset Password" link available on the login page if a password update is necessary.

This process helps maintain accurate and up-to-date staff records, ensuring contact information and personal details are correctly reflected in the system.
