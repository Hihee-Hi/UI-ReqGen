As an administrator using this system, you would: Select the start and end months and years to generate a report on the visits to the healthcare facility. Submit the selected date range, and the system will validate the entered dates to ensure the start date is before the end date and both dates are valid (not in the future). If valid, the system generates a graph showing trends in visit data over the selected period. This graph visually represents the number of visits per month for two categories: minors and adults. Hover over or reference the graph to analyze the data patterns and identify periods with the highest and lowest visits, allowing for better resource allocation and planning. If there was an error in date selection (like the end date being in the future), the system will alert you with an error message, guiding you to correct the input and try again. The graphical report is a tool for understanding visit trends over time, aiding in operational and strategic decisions for the facility.
