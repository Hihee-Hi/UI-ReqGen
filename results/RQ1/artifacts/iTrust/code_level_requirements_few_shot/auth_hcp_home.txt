As a healthcare provider (HCP) using this system, you would use your home portal to stay updated on various aspects of your practice. The portal offers a section for announcements regarding new system features, such as a user-friendly calendar popup for date selection. Notifications are also presented, where you can review comprehensive report histories, highlighting recent report requests you've made. If there are any report requests pending action, they will be listed for you to follow up on.

Additionally, the portal provides details about lab procedures that have been completed within the last month, along with a link to view all procedures. For each lab procedure, the patient's name and procedure ID are displayed. You’ll be able to see the procedure results, or be alerted if no results have been entered. This setup allows you to efficiently monitor patient lab procedures and manage report requests, making it easier to keep track of critical tasks and patient information within your healthcare practice.
