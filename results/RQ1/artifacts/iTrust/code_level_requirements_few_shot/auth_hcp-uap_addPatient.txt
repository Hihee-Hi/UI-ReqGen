As a healthcare provider (HCP) using this system, you would: Enter the patient's first name, last name, and email address into the form. After submitting the form, the system will create a new patient record and assign a unique Medical ID (MID) to the patient. The system will also generate a temporary password, which you can provide to the patient for them to reset their password later. You’ll see a confirmation message with the patient's MID and temporary password, and you’ll be prompted to continue managing the patient's information through another page. You cannot edit or view the patient's security details such as their password or security question. This process ensures that the new patient is added securely, with minimal input required from you, while protecting sensitive information like security questions and passwords.
