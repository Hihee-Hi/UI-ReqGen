As a user utilizing this system, you would first enter a unique user ID, referred to as the MID (Medical ID). This ID is used to search for users within the system. If a valid MID is entered, the system will retrieve and display the user's name, asking you to confirm if this is the correct user you intended to select. If it is correct, you can proceed by confirming the selection; otherwise, you have the option to search for another user by re-entering a different MID. If an error occurs due to an invalid ID or other issues, you will be promptly informed and can attempt the search again. This process is designed to ensure you accurately identify and select users through their Medical ID.
