As a healthcare provider using this system to add a new User Access Personnel (UAP), you would: Fill in the form with the UAP's first name, last name, and a valid email address. If the UAP doesn't have an email, substitute it with the hospital's predefined email to ensure password recovery is possible. Upon submission of the form, the system will create a new UAP profile, assigning them a unique Medical ID (MID) and a temporary password. You will receive a confirmation message containing the new UAP's MID and temporary password for you to communicate to them personally. This streamlined process allows you to efficiently onboard new personnel while ensuring secure handling of access credentials.
