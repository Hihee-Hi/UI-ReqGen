As an administrator using this system, you have access to multiple functionalities to manage healthcare operations efficiently. You can add new personnel such as healthcare providers, emergency responders, and public health authorities to the system. You can edit various system settings such as appointment types, hospital assignments, and procedural codes. The system allows you to send out appointment reminders to patients, ensuring they are kept up to date with scheduled visits. You also have tools to edit personnel information and manage hospital listings effectively. Furthermore, you have access to system reminders and can review satisfaction survey results, which help in assessing patient feedback. Lastly, you can manage session settings like the global session timeout to ensure security and optimize system operations. This menu offers a comprehensive set of options to support healthcare administration tasks and deliver quality service.
