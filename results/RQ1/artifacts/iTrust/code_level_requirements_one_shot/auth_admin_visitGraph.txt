As an administrator utilizing this system, you can visualize patient visit trends over a specified period. Begin by selecting the start and end months and years from dropdown menus and generate a report. The system will then compute the number of visits for minors and adults within the selected period. If any errors occur, such as entering a start date that's after the end date or selecting future dates, the system will display an error message. Once the report runs successfully, a graph will display showing the number of visits over the chosen months, differentiated by minors and adults for easy comparison.
