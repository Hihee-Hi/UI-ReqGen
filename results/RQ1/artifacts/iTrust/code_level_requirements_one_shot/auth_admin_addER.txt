As an administrator using this healthcare system, you are responsible for adding new Emergency Responders. To achieve this, you need to input the Emergency Responder's first name, last name, and email address into the designated fields of the form. Once you submit this form, the system creates a new Emergency Responder account, assigning a unique Medical ID (MID) and generating a temporary password for the new personnel. You will receive a confirmation message displaying the Emergency Responder’s MID and temporary password, which you need to communicate to the new responder. You will then have the option to continue to another page to further manage or edit personnel information. This process ensures that new responders are added efficiently and securely while you provide them with the necessary credentials to access the system.
