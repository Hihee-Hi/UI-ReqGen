As an administrator using this system, you can manage and maintain the list of appointment types offered within your organization. You have the ability to add new appointment types or update existing ones. You’d start by entering the name and duration for the appointment type you wish to add or update in the respective fields. Submit the form using the appropriate button for your action: either "Add Type" to create a new appointment type or "Update Type" to modify an existing one. If validation errors occur, such as missing information, the system will alert you to correct it. Additionally, you can view a list of current appointment types along with their durations. By clicking on an appointment type's name in the list, you can quickly autofill the form to update the appointment type's details. This setup facilitates efficient management of the services provided to clients by allowing you to keep appointment types up-to-date easily.
