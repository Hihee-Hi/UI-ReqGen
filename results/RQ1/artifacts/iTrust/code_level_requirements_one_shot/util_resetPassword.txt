As an individual using this system to reset a password, you would:

1. Start by entering your user role (e.g., Patient, Healthcare Provider, etc.) and your unique Medical ID (MID) to identify yourself.
2. If your role and MID match the system's records, you'll be prompted to answer a security question related to your account.
   - If you haven't set a security question, the system will inform you, and you won't be able to proceed with the reset.
3. Provide the answer to the security question, along with your desired new password and a confirmation of the new password.
4. Upon submission, the system will validate your input. This includes checking the correctness of the security answer and ensuring the new password meets the necessary criteria.
   - If these validations fail, the system will prompt you to try again.
5. If successful, the system will confirm that your password has been reset, allowing you to use the new password to log in.

This process ensures that password reset requests are secure, requiring role verification, security questions, and strong password criteria to prevent unauthorized account access.
