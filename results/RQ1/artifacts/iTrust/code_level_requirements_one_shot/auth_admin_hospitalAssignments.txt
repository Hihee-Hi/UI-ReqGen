As an administrator using this system, you can manage staffing assignments for healthcare providers (HCPs) to various hospitals. To begin, make sure a valid personnel ID is in the system. If it's missing, you'll be redirected to enter it. Once the ID is confirmed, you'll see a list of hospital assignments associated with the provider, along with a separate list of available hospitals. You can easily move the provider between hospitals by clicking "Assign" for assigning them to a new hospital or "Unassign" to remove their assignment. This ensures that healthcare providers are allocated properly across facilities, helping to maintain adequate staffing levels and facilitate efficient healthcare management.
