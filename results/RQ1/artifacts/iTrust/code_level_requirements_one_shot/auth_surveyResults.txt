To use this system for searching Health Care Provider (HCP) survey results, you should start by deciding whether to use a zip code or a hospital ID as your primary search criteria; the system will not allow using both simultaneously. Additionally, you have the option to refine your search by selecting a specialty. Upon submitting the search, if the criteria are valid, the system will display survey results related to HCPs, including their contact information, specialty, and performance metrics such as wait times and satisfaction ratings. If no results match your search criteria, the system will prompt you to adjust your criteria and try again. If successful, you can view detailed information about the HCPs from the search results.
