As a user of this system, you will notice that if the server experiences a reboot, a message is displayed indicating "Server Reboot!" which informs you that your current session and credentials have been lost due to this reboot. This means you will need to log back into the system to resume your activities. By clicking on the provided link, you will be redirected to the login page where you can enter your credentials to access the system again. This ensures that user sessions are securely terminated during unexpected server events, maintaining privacy and data protection.
