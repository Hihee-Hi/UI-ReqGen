As a user interacting with a flight route management system, you are prompted when attempting to make changes that could potentially lead to losing unsaved modifications. This includes editing another route, switching to a different route, creating a new route, or deleting an existing route. When such actions are detected with unsaved changes present, a confirmation message is displayed. You are given the choice to either proceed, thereby discarding unsaved changes, or cancel the action to return and save your changes. Confirming a discard action will execute the new operation without saving, such as switching routes or confirming a deletion request following another confirmation step. This ensures users are aware of and can prevent unintended data loss while managing flight routes efficiently.
