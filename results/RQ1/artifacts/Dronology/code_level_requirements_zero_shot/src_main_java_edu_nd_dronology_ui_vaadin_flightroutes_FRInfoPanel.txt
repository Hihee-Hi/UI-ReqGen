This application provides a user interface for managing and viewing flight routes for drones. When using this system, you can view a list of available drone flight routes and see how many are present in the database. When a new route needs to be added, you can click a button labeled "Add a new route," which brings up a window to input information for the new route. The interface accounts for whether changes are being made by ensuring any unsaved changes are highlighted if you attempt to switch contexts. You can interact with the list to select and switch between different flight routes. The system automatically updates and presents the most current list of routes for viewing or modifying.
