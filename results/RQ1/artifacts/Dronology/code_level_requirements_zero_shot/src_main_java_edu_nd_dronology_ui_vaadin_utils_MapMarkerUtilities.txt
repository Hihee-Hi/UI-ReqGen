This system lets users manage and visualize flight routes by interacting with a digital map. Users can add, adjust, and remove markers representing waypoints, ensuring their path is correctly plotted and documented. It provides a dynamic experience through interactions such as clicking and dragging, enabling the seamless update of these routes. Additionally, users can choose different modes for displaying route lines, which indicate the status or focus of various segments, offering a clearer understanding of active or completed paths. As a result, this enhances the process of planning and reviewing flight routes for efficient navigation and oversight.
