This system allows users to manage and edit flight routes visually on a map. When a route is in edit mode, users can perform operations to enhance their route planning experience. Users can add new waypoints by left-clicking on the map and reposition existing waypoints by dragging them to the desired locations. Through interacting with a visible edit bar, they can choose to either save or cancel their ongoing changes. If they opt to cancel, all modifications are rolled back to the previously stored route settings. Saving the route updates the system's records and generates an updated map display. In this process, the system ensures that all data is correctly synchronized by validating that the saved path correctly reflects user edits. The interface adjusts dynamically as users toggle between editing and non-editing modes, providing a seamless route management experience.
