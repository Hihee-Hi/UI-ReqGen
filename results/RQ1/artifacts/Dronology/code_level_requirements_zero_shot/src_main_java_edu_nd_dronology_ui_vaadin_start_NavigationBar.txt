As a user of this system, you interact with a navigation interface that enables you to switch between two main functionalities related to drone operations. Primarily, these functionalities include monitoring ongoing flights and managing flight route information. Upon accessing the interface, you are presented with a navigation menu at the top of the page. The menu provides two options: "Active Flights" and "Flight Routes", each represented by an icon for easy identification. Selecting "Active Flights" displays a layout featuring current flight activities, allowing you to monitor and interact with ongoing operations. By choosing "Flight Routes", you switch to a different layout that focuses on planning, modifying, and reviewing the paths that drones will take. The transition between these views is seamless, and noticeable visual feedback is provided to highlight the current selection, ensuring that you can easily use this tool to manage and oversee various aspects of drone activities efficiently.
