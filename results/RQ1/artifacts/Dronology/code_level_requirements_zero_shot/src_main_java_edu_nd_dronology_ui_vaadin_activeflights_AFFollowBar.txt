The user interface provides a tracking feature specifically within a drone operation context. It displays when multiple drones are being actively monitored. Users can initiate or halt the active-following mode that facilitates real-time monitoring of drones. When users choose to 'stop following,' the system ceases the real-time tracking and reverts to a broader view, centering the map to include all drones' positions. This interface is particularly significant in contexts where maintaining current awareness of multiple drones' activities in real-time is critical, such as in aerial surveying or delivery services. Users interact with this interface through visual feedback indicating active drones and actionable controls to manage the follow mode efficiently.
