When you interact with the system, a map interface will be displayed showing various flight routes as polylines. If you click on any polyline on the map, the system will allow you to add a waypoint at the point where you clicked. This will open a window for inputting additional details like altitude and transit speed for the waypoint you are adding. The system checks if the map is in an editable state before allowing these changes, ensuring that users can only modify routes when permitted. This functionality is useful in planning and adjusting flight paths dynamically, particularly relevant for drone operations requiring precise route adjustments and the management of path-specific settings.
