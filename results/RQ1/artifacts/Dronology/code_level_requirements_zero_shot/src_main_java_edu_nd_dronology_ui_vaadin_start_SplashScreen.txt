As a user interacting with this system, you will see a welcome screen, which provides a pleasant introduction while the application is setting up. This will help create a welcoming and professional first impression as you access the Dronology system. You will be greeted with an image featuring a drone, accompanied by a note that says "Welcome to Dronology." To give you an indication that the application is loading, a progress bar is displayed with the label "Loading...". Although in this version, the progress bar might fill up quickly as it simulates the loading process. This interaction aims at ensuring you feel informed and engaged while the application prepares itself for you to begin using it.
