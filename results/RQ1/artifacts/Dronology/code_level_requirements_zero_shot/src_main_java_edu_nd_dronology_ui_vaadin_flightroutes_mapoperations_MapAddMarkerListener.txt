This system allows users to interact with a map by adding waypoints through clicks. When a user clicks on the map, a waypoint is added, and a window pops up, prompting the user to enter details such as altitude and transit speed for this waypoint. If a user changes their mind, they can also delete a waypoint. This feature is particularly useful in applications involving navigation or route planning, where users need to define specific paths or destinations on a map, such as in drone navigation systems. Users start by clicking anywhere on the map to place a waypoint; immediately, they are prompted to provide additional information to finalize that waypoint's configuration. The system ensures that waypoints are only added when the map is in an editable state, providing users with control over when and where route modifications occur.
