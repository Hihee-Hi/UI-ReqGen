This application allows users to set a takeoff altitude for a drone through an interactive window. Upon opening the window, the user enters the desired altitude in meters and can confirm the action to initiate the drone's takeoff. If the input is invalid, it defaults to a preset altitude. The user can also cancel the action to close the window without proceeding with the takeoff. Through these interactions, the system ensures that the drone's takeoff altitude is specified consistently while providing a simple interface for user control.
