In managing flight routes, users interact with an information panel located above the map that details the selected route's specifics. This panel enables users to perform actions such as editing or deleting the route. Users can easily toggle options for automatic zooming to the route or displaying tabular views of route data. Double-click functionality allows users to edit the route's name and description directly within the panel. When no route is selected, the panel clearly indicates this, ensuring users are always aware of their current selection status. Users can also see a concise summary of the number of waypoints in the current route, helping them understand the route's complexity at a glance.
