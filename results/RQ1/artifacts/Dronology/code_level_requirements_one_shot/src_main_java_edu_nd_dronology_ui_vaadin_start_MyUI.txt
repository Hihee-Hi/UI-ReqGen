As a user of this system, you start interacting with the application through an entry point that establishes a connection to retrieve and manage drone-related information. Upon launching, you see a navigation bar that serves as the central hub for accessing various functionalities. Every second, the system automatically updates drone data, ensuring that you have the latest information on their status and operations. This includes refreshing a list of drones being monitored, identifying any you have selected to focus on, and updating a map view to reflect the monitored drones' current positions. This real-time update aids in maintaining situational awareness and control over the drone operations you oversee.
