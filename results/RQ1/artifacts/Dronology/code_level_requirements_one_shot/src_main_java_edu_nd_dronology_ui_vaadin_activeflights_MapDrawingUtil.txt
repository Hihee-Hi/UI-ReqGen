When monitoring drone flights on the map, users can interact with various visual elements to track and manage the operation. Each drone's route can be depicted on the map, with focused drones having their route highlighted for easy identification. Users can observe changes in flight routes as they dynamically update when a waypoint is reached or a new route is activated. Drone icons indicating their current position update in real-time, allowing users to focus on specific drones or a group of interest. If there are changes in active drones (e.g., some going offline or new ones being activated), the map automatically reflects these updates to ensure accurate operational monitoring.
