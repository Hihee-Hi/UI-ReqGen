When monitoring active flights, users have the ability to utilize a follow mode to keep track of specific unmanned aerial vehicles (UAVs). This mode displays a list of the UAVs currently being followed, allowing users to see which drones are under their watch in real-time. If users decide to stop monitoring these UAVs, they can click a button to cease following them, which will then return the interface to a standard viewing mode centered on the general area of interest. The system ensures that any changes in the list of UAVs being monitored are immediately reflected, providing ongoing clarity in UAV operations management.
