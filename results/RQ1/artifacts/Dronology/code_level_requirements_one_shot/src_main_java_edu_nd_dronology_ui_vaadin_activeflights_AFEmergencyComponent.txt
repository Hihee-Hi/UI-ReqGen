Users have access to a dedicated section for emergency operations on the active flight information panel. Through this, they can issue crucial commands to all drones simultaneously. If an urgent situation requires the drones to hover in place, users can activate this command to keep them stationary in the air. Alternatively, if conditions necessitate an immediate return, users can initiate a command to send all drones back to their base or home location. This feature ensures quick responses during critical situations, enhancing the safety and management of drone operations.
