In the active flights management system, the primary interface consists of a control panel and a map component. Users have the ability to interact with the map to manage and monitor drone operations effectively. They can opt to view the current position of drones on the map or enable a follow mode, which ensures the map centers around selected drones and adjusts its zoom level automatically to keep them in view. This functionality facilitates real-time monitoring of drone positions, aiding in efficient flight management and supervision.
