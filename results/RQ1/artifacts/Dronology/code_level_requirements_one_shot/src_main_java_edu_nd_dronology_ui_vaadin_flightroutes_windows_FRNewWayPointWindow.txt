In this system, users planning flight routes have the ability to specify key waypoint details, such as altitude and transit speed, for their drones. Through an interactive window, users input these parameters, ensuring they are numeric values to enable a successful save operation. If the inputs are valid, the waypoint is then incorporated into the flight route, updating the pathway visualization and waypoint count accordingly. Should users choose not to save their input or encounter input errors, they can cancel the operation, which removes the unsaved waypoint from the map display. This process delivers precision in flight route adjustments, enhancing navigation accuracy in drone operations.
