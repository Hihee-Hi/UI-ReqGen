In managing active drone flights, users interact with the map system to oversee and control drones in real-time. The map provides a dynamic and interactive view of all active drones and their flight paths. Users can centralize the map view to focus on all drones collectively or specific ones in "follow" mode, automatically adjusting the map's center and zoom to ensure all relevant drones are visible.

Users can interact with drones directly through the map; hovering over a drone reveals detailed information about it, such as its current status, which can assist in decision-making. Additionally, the system provides pop-ups with precise waypoint data when hovering over specific points on a flight path, furnishing users with valuable navigation details such as the latitude, longitude, altitude, and transit speed.

This setup ensures that users maintain seamless supervision of aerial operations, allowing swift responses to changes or anomalies during flights. Such interaction is vital for efficiently managing flights and ensuring drone operations adhere to planned routes. The interface enhances situational awareness for users, empowering them to make informed, real-time decisions in overseeing drone activities.
