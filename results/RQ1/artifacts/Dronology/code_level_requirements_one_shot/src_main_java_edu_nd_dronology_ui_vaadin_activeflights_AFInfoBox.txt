When managing an active flight, the user interacts with the drone information panel to perform essential tasks. This includes instructing a drone to take off to a specified altitude, commanding it to return immediately to its home position, or assigning a new route as required. Moreover, users can enable the hover-in-place feature, keeping the drone stationary in the air. To ensure continuous control, if any communication issues arise, users can quickly resend the last command given to the drone.
