Users who want to manage flight routes can view all waypoints on a map and associated data, such as latitude, longitude, altitude, and transit speed, in a tabular format. They have the ability to edit this information directly within the table, ensuring accurate and up-to-date location data of the waypoints. While in edit mode, users can easily delete waypoints with dedicated buttons, ensuring they maintain precise control over the flight route data. Additionally, each change is reflected visually on the map, allowing for confirmation and visualization of waypoint adjustments in real-time. This system's grid setup facilitates a clear and organized view, enabling efficient route planning and adjustment.
