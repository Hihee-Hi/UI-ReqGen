When operating within a map interface in flight route planning, the user can navigate and interact with waypoints, which represent specific locations on the map. When the mouse pointer exits a waypoint, any informational pop-up that was displaying details about that point is automatically closed. However, in edit mode, the system intelligently allows the user to continue interacting with the pop-up, particularly to enable access to the remove waypoint option if the pointer exits towards the bottom right corner of the map. This functionality supports seamless waypoint management, ensuring efficient and error-free operations when adjusting flight paths.
