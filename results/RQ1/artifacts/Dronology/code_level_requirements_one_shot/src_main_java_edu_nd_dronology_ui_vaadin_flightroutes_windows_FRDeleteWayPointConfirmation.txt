When planning or managing flight routes, the user may need to remove certain waypoints. A confirmation prompt will appear, asking the user to confirm if they indeed want to delete the waypoint. This ensures that waypoints aren't removed unintentionally. If the user confirms, the system will proceed to delete the waypoint, update the visual map to reflect this change, and maintain an accurate count of the remaining waypoints on the route. This interaction helps in ensuring that the route is tailored exactly to the user's specification without errors in waypoint management.
