In this system, users are provided a panel to interact with multiple drones, termed UAVs, simultaneously. The primary function of the interface is monitoring and control. Users can view active drones, and for each drone, an information box offers options to manage its state. Users can command all drones to return home, which involves a confirmation step to ensure critical decisions are intentional. The panel displays the number of active drones and provides options to select or deselect all drones, making broad operations convenient. Expand or collapse views of these information boxes are available to streamline viewing preferences. The system regularly refreshes to update drone statuses, adding new drones when detected and removing those no longer active. If any disconnection happens, it reconnects to fetch fresh data, ensuring information remains timely and accurate for effective decision-making.
