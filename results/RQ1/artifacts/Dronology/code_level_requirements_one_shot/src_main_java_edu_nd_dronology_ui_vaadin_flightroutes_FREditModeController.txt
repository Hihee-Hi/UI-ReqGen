When managing flight routes, users can interact with the route editor to modify existing flight paths. When in edit mode, users can add new waypoints by left-clicking on the map or move existing ones by dragging them. If the user decides to discard changes, they can click the cancel button, reverting the route to its previous state. To save changes, users click the save button, which ensures the updated waypoints and route details are sent to the central system for storage. These operations allow users to maintain efficient and accurate route plans, ensuring optimal flight path management. When exiting edit mode, the routes are updated to reflect any modifications made.
