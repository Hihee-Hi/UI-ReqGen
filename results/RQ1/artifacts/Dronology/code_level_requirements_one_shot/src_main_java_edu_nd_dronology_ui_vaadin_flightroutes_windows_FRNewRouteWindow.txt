When you want to create a new flight route, you are welcomed with a window where you can input both the name and description of this route. After providing this information, you have two choices: either proceed to draw the route or cancel the operation. If you opt to draw the route, the system will save the new route and offer to switch directly to editing this newly added route, giving you a seamless transition into route customization. If at any point you decide against creating this route, simply cancel to close the window without making changes.
