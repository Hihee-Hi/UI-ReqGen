When you want a drone to take off, you specify the altitude directly in a prompt window. First, you enter the desired altitude in meters. There is a default value provided, but you can change it as needed. If you accidentally enter an invalid value, it will reset to the default. Once you've set the correct altitude, simply confirm to send the takeoff command, and the drone will ascend to the specified altitude. If you need to cancel the operation, there’s a cancel option available, and the window will close without any action taken.
