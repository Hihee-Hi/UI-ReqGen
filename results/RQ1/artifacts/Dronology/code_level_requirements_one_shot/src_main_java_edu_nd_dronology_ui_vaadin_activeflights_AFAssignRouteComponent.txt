When managing a fleet of drones, you may need to assign specific flight routes to each drone. This feature allows you to select the desired flight path for a drone from the available options and assign it. You can view and verify details such as current status, battery life, and coordinates before assigning routes, ensuring you maintain optimal operation. Additionally, if a flight path is unsuitable or assigned incorrectly, you can easily remove it. You can also activate a hover mode, enabling the drone to maintain its position, or instruct the drone to return home if needed, potentially due to unexpected conditions or planned route changes.
