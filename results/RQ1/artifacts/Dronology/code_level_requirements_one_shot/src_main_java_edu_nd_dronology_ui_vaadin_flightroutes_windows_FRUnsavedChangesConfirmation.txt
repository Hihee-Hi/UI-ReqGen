In the context of managing flight routes, users are notified when they attempt actions that could lead to losing unsaved changes for a particular route. If users try to edit a different route, delete a route, create a new one, or switch routes without saving changes to the current one, they are prompted with a confirmation message. The system offers users two options: proceed with the action and discard changes, or cancel the action to save changes. These preventive measures ensure that users consciously decide on potential loss of their unsaved edits to flight routes.
