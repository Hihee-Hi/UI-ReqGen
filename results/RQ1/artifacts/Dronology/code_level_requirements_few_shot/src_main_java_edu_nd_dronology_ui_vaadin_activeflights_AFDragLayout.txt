This system provides users with a user interface component that facilitates managing and organizing flight route plans for drones. When dealing with multiple flight routes, users can view the available pending flight plans associated with a specific drone. These plans are presented as movable boxes, which users can drag and drop within the interface to prioritize or reorder them according to their operational needs.

The interface handles these tasks through intuitive actions, allowing for seamless reshuffling of flight plans without any cumbersome process. Users initiate drag-and-drop actions to reposition plans as required, helping them to dynamically adjust to changing priorities or operational constraints. This becomes particularly valuable in scenarios requiring quick adaptability or modification of drone tasking sequences. The system essentially streamlines the organizational aspects of drone operation planning by offering a visual and interactive method to manage flight plan assignments effectively.
