When planning a flight route, users are prompted to input specific details for each waypoint through a dedicated interface. This interface consists of a window where users can specify the desired altitude and transit speed for the drone at that waypoint. Upon entering these details, users can save their inputs, which will update the waypoint's attributes and reflect the changes in the route overview. If there are any errors or missing information, such as non-numeric input, users will receive immediate feedback to correct the issue. Additionally, users have the flexibility to cancel the operation if needed, ensuring an intuitive and accurate planning process.
