When working with flight routes, if a user attempts to perform certain actions without saving changes, the system intervenes to confirm whether they wish to discard the unsaved modifications. For instance, if a user seeks to switch to editing another route, create or delete a route, a confirmation prompt appears to ensure they intend to proceed without preserving their current work. This mechanism aids in preventing accidental loss of unsaved changes. Upon agreeing to discard changes, the system smoothly transitions to the next task as chosen by the user. If not, the system will continue with the current route editing session, providing an option to cancel the new route creation if needed.
