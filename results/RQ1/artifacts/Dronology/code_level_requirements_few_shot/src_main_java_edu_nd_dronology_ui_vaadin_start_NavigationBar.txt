Users interact with a navigation bar that allows them to switch between two primary views: Active Flights and Flight Routes. When a user selects 'Active Flights', the system displays real-time data and controls related to the current status and operations of active drones. Choosing 'Flight Routes' redirects them to a layout where they can manage and monitor predefined flight paths for their drones. This navigation bar provides a straightforward way to switch contexts, ensuring users can smoothly transition between monitoring live drone activity and managing planned routes.
