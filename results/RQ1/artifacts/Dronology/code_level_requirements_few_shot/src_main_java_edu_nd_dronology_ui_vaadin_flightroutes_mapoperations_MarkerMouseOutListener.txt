As a user interacting with a map interface for managing flight routes, when you hover over a waypoint, a popup will appear displaying relevant information or options. If the mouse moves away from this waypoint, the system will automatically close the popup except when you are in edit mode and your mouse movement indicates that you want to access options like removing the waypoint, which typically appears at the bottom right of the popup. Therefore, if you move the cursor towards this area when the map is in edit mode, the popup will remain open, allowing you to interact with these controls conveniently. This ensures you can easily modify flight routes without unnecessary interruptions.
