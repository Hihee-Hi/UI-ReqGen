When using this system, you will be prompted to enter the altitude for a drone's takeoff in a dialog box. You can specify the desired altitude level in meters. If you don't input a valid number, the system will automatically reset the altitude to a default value. Once you confirm the entered altitude is correct, you can proceed with the takeoff command, triggering the drone to ascend to the specified height. If you change your mind, you can cancel this operation at any time.
