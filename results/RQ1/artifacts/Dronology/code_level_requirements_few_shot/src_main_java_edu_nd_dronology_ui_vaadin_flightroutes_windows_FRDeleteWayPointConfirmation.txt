When managing flight routes, users may need to remove specific waypoints. If a user decides to delete a waypoint, the system prompts with a confirmation window asking if they are sure about this action. The user can either confirm the deletion or cancel the request. Confirming will remove the waypoint from the current planning view, ensuring the route is kept up-to-date without the unwanted point. This provides a safeguard against accidental data loss while dynamically managing waypoints in the route planning stage.
