When using the map interface to manage flight paths, placing the mouse cursor over a waypoint triggers a popup that provides specific information about that location. This popup displays the latitude, longitude, altitude, and transition speed associated with the waypoint. If you have editing privileges, a delete button is available for removing waypoints. The system automatically adjusts the popup's position on the screen to ensure it is always visible, accommodating different screen sizes and resolutions. This feature is optimized for real-time interaction, enhancing the user's ability to scrutinize and manage navigational details efficiently.
