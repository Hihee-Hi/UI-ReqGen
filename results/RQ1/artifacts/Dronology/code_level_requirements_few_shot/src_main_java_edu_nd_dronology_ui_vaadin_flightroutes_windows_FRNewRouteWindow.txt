Users can initiate the creation of new flight routes by providing a name and an optional description. This process involves entering the desired route details in a designated window and confirming the action. Upon confirmation, the system processes the input and adds the new route to the list of available routes. The user interface will then update to reflect the addition of the new route, automatically switching to it and enabling edit mode, allowing users to further customize the newly created route if needed. If users decide to cancel the operation at any point, they can easily close the input window without making any changes.
