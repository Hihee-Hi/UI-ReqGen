As a user planning a flight route for drones, you can interact with an intuitive map interface. When planning, you can create and manage waypoints that dictate the drones' flight paths. You have the option to input specific altitude and speed details for each waypoint. The map will automatically update to reflect any changes you make, visualizing both the location and connections between waypoints. If needed, you can enter an edit mode to make precise adjustments or delete waypoints, ensuring the flight route meets your specifications. For each route, a description is readily accessible, providing context or specific details relevant to the flight. As you select different flight routes, the interface will update to highlight route details and keep the flight information organized.
