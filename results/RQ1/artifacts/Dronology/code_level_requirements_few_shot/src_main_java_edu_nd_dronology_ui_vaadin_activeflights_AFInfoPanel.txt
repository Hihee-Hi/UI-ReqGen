Users can efficiently manage and monitor multiple drones through an intuitive side panel interface. The panel displays a collection of drone info boxes, each representing an active drone. Users can expand or collapse the boxes to view details such as status and battery life. To streamline operations, users can select or deselect all drones with a single click. For specific actions, users can focus on individual drones, which updates their selection status and highlights them for easier tracking. Additionally, in urgent situations, users can employ a feature to send one or several selected drones back to their home base, with confirmation dialogs preventing accidental commands. The system also automatically adjusts the list when new drones are activated or existing ones are deactivated, ensuring users have the most recent information.
