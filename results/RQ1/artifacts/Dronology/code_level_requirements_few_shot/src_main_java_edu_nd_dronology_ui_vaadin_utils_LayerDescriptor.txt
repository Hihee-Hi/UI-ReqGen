When viewing the map, you can manage multiple layers that provide various types of visual information. Each layer on the map has a specific name and is tied to a unique identifier, typically a URL. Some layers may be marked as overlays, meaning they are intended to be displayed over existing map features without completely replacing what is already visible. You can add new layers to enhance your map's informational richness, as well as keep track of which layers are currently active. This setup helps in dynamically adjusting the visual data presented on the map to suit specific analysis needs.
