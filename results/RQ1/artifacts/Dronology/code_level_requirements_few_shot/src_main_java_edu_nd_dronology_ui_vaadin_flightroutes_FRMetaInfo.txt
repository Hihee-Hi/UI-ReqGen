The system allows users to interact with the flight route information of unmanned aerial vehicles through a dedicated info bar above a map. Users can view details of selected routes, including the route name, description, and the number of waypoints. For any selected route, users can perform actions like entering edit mode, which allows modifications to the route's name and description, or deleting the route altogether. Additionally, users can set preferences such as automatic zooming to the route on the map or toggling between table views of the route information. If no route is selected, users will receive a cue that no information is available.
