In this system, users can seamlessly manage and monitor an array of active flights through a primary interface. The core functions allow users to switch the map view between following selected drones or maintaining a standard view. In the follow mode, the map actively tracks selected drones, maintaining them at the center of the screen to facilitate continuous oversight. Users interact by clicking buttons that dictate the view preference, thus simplifying the supervision of multiple drone operations with minimal manual intervention. The essential controls within the interface ensure that even in changing conditions, users can efficiently adjust their monitoring focus.
