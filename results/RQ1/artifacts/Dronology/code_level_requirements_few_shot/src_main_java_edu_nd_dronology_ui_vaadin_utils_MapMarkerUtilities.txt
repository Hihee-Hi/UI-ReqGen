When setting up or managing flight routes, users can visually interact with a map interface to plot waypoints and track connections between them. Users can easily add new waypoints, adjust existing ones, and see live updates to the paths drawn on the map. Each waypoint has distinct markers that change color based on its position in the sequence: starting points, endpoints, or midpoints. For added precision, users can modify the route lines' color and style based on status such as completion or focus, aiding in route visualization. Additionally, the system allows users to toggle an editable mode, enabling or disabling the ability to modify routes directly on the map. This functionality is particularly beneficial for planning and monitoring flight paths efficiently.
