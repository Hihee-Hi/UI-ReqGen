As a user interacting with the system, you can view and manage details related to specific points on drone flight paths, known as waypoints. Each waypoint is defined by its geographical coordinates, including latitude, longitude, altitude, and transit speed. The system provides information on whether the drone has reached the waypoint. Users can retrieve these details, modify them as needed, and ensure the waypoints are correctly configured for smooth drone navigation. This functionality ensures effective route planning and monitoring of drone paths.
