As a user, you can manage and control drone missions through an interface. The system enables you to carry out missions by uploading and executing mission plans with ease. You can begin a mission by clicking the "Execute Mission" button, which uploads the necessary mission data. If the mission requires cancellation at any point, you can quickly abort it by selecting the "Cancel Mission" option, which halts all planned mission activities. This functionality allows you to manage drone operations effectively, ensuring that missions are initiated and terminated based on real-time requirements.
