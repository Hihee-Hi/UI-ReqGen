This interface facilitates users in assigning new flight routes to unmanned aerial vehicles (UAVs). Initially, users can view a panel displaying the current status of a UAV, including its health and battery life. Users are guided through selecting available flight routes, which include detailed waypoints essential for the UAV's navigation. If users attempt to choose a route without designated waypoints, they receive an alert, preventing them from assigning incomplete flight paths. Users can preview selected routes and make necessary adjustments before finalizing. The system enables users to assign multiple routes in sequence, allowing a continuous and efficient operation. Users also have control to cancel the process or apply the routes to the UAV, making changes as needed. In emergencies, they have the option to command the UAV to return to its home base swiftly or to hover at its current location, ensuring flexibility in operation management.
