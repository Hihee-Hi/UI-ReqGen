When using the map interface to manage flight routes, users can click on a specific line representing a segment of a flight path. This action allows the user to add a new point midway through the line to further customize the drone's route. Upon clicking, the system enables the user to input details such as desired altitude and speed at that point, offering greater control over the route adjustments. This feature is most applicable to users needing precise navigation changes or testing scenario-based adjustments along a drone's pathway.
