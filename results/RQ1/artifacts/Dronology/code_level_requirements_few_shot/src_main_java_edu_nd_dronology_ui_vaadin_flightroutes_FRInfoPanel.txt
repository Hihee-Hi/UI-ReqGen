As a user, you can manage and organize your drone flight routes efficiently. At the top of the panel, you'll see the total number of routes available in your database. You can create new routes by clicking the "Add a new route" button, which will bring up a dedicated interface for inputting new route details. Should you have unsaved changes while navigating away from an ongoing route setup, the system will prompt you with a confirmation option to ensure no data is lost. The list of flight routes is easily navigable and provides quick access to specific routes, allowing you to switch between them without losing your place. Routes are maintained up-to-date, reflecting any recent changes or additions you've made.
