To interact with the system, users can view a map that shows the positions of active drones. The map updates in real-time, displaying lines connecting the waypoints of each drone's flight path. Users can focus on a specific drone, which will highlight its route in a distinct color, making it easier to track. Additionally, users can select or deselect drones to display or hide their respective routes. This interface is particularly useful for monitoring multiple drones and ensuring their flights are following the intended paths.
