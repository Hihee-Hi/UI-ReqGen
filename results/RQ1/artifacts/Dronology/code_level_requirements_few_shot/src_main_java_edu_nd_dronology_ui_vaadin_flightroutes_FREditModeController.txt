When planning and managing flight routes, the user is able to engage an edit mode to modify an existing route. This enables the addition of new waypoints via left clicks on the map, while existing waypoints can be moved by dragging them to desired positions. The user can save changes by pressing the save button, which updates the route information and sends these modifications to the backend for permanent storage. Alternatively, pressing the cancel button allows the user to exit edit mode, reverting any unsaved changes and restoring the route to its previous state. The interface provides a clear visual indication that a route is being edited and reflects changes immediately on both the map and additional flight route displays.
