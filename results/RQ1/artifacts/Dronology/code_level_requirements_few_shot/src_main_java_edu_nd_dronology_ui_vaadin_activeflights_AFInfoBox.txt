When managing an active flight, you can interact with each drone's information panel to perform critical operations. You can instruct a drone to take off to a designated altitude, immediately command it to return to its home location, or assign a new route if needed. You also have the option to enable a hover-in-place mode, allowing the drone to stay stationary mid-air. If communication issues occur, you can quickly resend the last issued command to the drone to maintain control and ensure flight continuity.
