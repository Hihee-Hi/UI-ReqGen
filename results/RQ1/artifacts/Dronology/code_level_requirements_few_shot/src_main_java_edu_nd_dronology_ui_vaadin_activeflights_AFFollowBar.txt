When overseeing active flights, the user is informed when the system is set to follow specific drones. In follow mode, the interface clearly displays the names of the drones being tracked. The user can easily stop this mode by pressing a dedicated button, which then returns the display to a normal view where the map centers itself relative to all drones instead of focusing on specific ones. This feature is designed to help users maintain attention on key drones during critical operations and effortlessly switch perspectives when needed.
